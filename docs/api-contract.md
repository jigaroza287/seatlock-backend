# API Contracts

## Event

### Endpoints

| Method | Path              | Body                                                                               | Success                                 | Error                                                                                    |
| ------ | ----------------- | ---------------------------------------------------------------------------------- | --------------------------------------- | ---------------------------------------------------------------------------------------- |
| POST   | `/api/events`     | `{ title, description, category, durationMins, language }`                         | 201 + created event + `Location` header | 400 invalid body, 409 title already used by another event                                |
| GET    | `/api/events`     | None                                                                               | 200 + paginated list                    | 400 invalid query params                                                                 |
| GET    | `/api/events/:id` | None                                                                               | 200 + full event object                 | 400 invalid id format, 404 not found                                                     |
| PATCH  | `/api/events/:id` | Any non-empty subset of `{ title, description, category, durationMins, language }` | 200 + full event object                 | 400 invalid body or `id` in body, 404 not found, 409 title already used by another event |
| DELETE | `/api/events/:id` | None                                                                               | 204 No Content (empty body)             | 400 invalid id format, 404 not found                                                     |

All error responses use the [error shape](#error-shape).

### Event object

| Field        | Type   | Required on create       | Rules                                                |
| ------------ | ------ | ------------------------ | ---------------------------------------------------- |
| id           | string | No (generated by server) | UUID v7; read-only, cannot be updated                |
| title        | string | Yes                      | Non-empty; unique across events, 1 to 100 characters |
| description  | string | Yes                      | Non-empty, 20 to 2000 characters                     |
| category     | string | Yes                      | One of the [allowed categories](#categories)         |
| durationMins | number | Yes                      | Positive integer                                     |
| language     | string | Yes                      | ISO 639-1 language code (e.g. `en`, `hi`)            |

#### Categories

```ts
type Category = 'concert' | 'comedy' | 'theatre' | 'sports' | 'movie';
```

### List response shape

```ts
{
  data: Event[];
  pagination: {
    limit: number;
    offset: number;
    total: number;
  };
}
```

### List query params

| Param    | Type   | Default | Description                                   |
| -------- | ------ | ------- | --------------------------------------------- |
| limit    | number | 20      | Page size, positive integer                   |
| offset   | number | 0       | Number of items to skip, non-negative integer |
| search   | string | —       | Case-insensitive match on `title`             |
| category | string | —       | Filter by one of the allowed categories       |

Results are sorted by `title` ascending.

### Error shape

```ts
{
  error: {
    code: string; // machine-readable, e.g. "EVENT_NOT_FOUND"
    message: string; // human-readable description
    details?: unknown; // e.g. per-field validation errors
    requestId: string;
  };
}
```
