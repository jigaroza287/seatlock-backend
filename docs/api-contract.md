# API Contracts

Source of truth for the HTTP API. Field rules follow `prisma/schema.prisma` and the constraints in `prisma/migrations/`. Database error mapping follows [pg-errors.md](./pg-errors.md).

## Conventions

- Base path is `/api`. Request and response bodies are JSON.
- Ids are UUID v7, generated by the server. A malformed id in the path returns 400.
- Text fields are trimmed before validation. Length rules apply to the trimmed value.
- Success responses use `{ data }`. Lists use the [list response shape](#list-response-shape).
- Create returns 201 with a `Location` header pointing to the new resource.
- Delete returns 204 with an empty body.
- POST and PATCH reject unknown fields, read-only fields and `id` in the body with 400.
- PATCH accepts any non-empty subset of the writable fields. A missing resource returns 404 before any 409.
- Every response carries an `X-Request-Id` header, with the same value as `error.requestId`. A client may send its own `X-Request-Id` (up to 128 characters) and the server reuses it; otherwise the server generates a UUID.
- A parent id in the path that does not exist returns 404 (`<PARENT>_NOT_FOUND`). A referenced id in the body that does not exist returns 400 (`VALIDATION_ERROR`) with the field in `details`.
- Money is an integer in minor units (paise), named `priceMinor`. Never a float.
- Timestamps are ISO 8601 strings. Requests must include an offset (`Z` or `+05:30`). Responses are in UTC, e.g. `2026-11-20T09:00:00.000Z`.
- In a query string, encode `+` as `%2B` (e.g. `2026-11-20T00:00:00%2B05:30`). An unencoded `+` decodes to a space and returns 400.

### List query params

Every list endpoint accepts these, plus its own filters.

| Param  | Type   | Default | Description                                   |
| ------ | ------ | ------- | --------------------------------------------- |
| limit  | number | 20      | Page size, integer from 1 to 100              |
| offset | number | 0       | Number of items to skip, non-negative integer |

### List response shape

```ts
{
  data: T[];
  pagination: {
    limit: number;
    offset: number;
    total: number;
  };
}
```

### Error shape

```ts
{
  error: {
    code: string; // machine-readable, e.g. "EVENT_NOT_FOUND"
    message: string; // human-readable description
    details?: { field: string; message: string }[]; // per-field validation errors
    requestId: string;
  };
}
```

### Error codes

| HTTP | Code                    | When                                                                                                            |
| ---- | ----------------------- | --------------------------------------------------------------------------------------------------------------- |
| 400  | `VALIDATION_ERROR`      | Invalid body, query, path id or malformed JSON; missing referenced id                                           |
| 404  | `<ENTITY>_NOT_FOUND`    | Resource or parent resource does not exist                                                                      |
| 404  | `ROUTE_NOT_FOUND`       | No route matches the method and path                                                                            |
| 409  | `<ENTITY>_CONFLICT`     | Unique constraint hit, shows would overlap, show on a screen with no seats, or delete blocked by dependent rows |
| 500  | `INTERNAL_SERVER_ERROR` | Unexpected error                                                                                                |

`<ENTITY>` is one of `EVENT`, `VENUE`, `SCREEN`, `SEAT`, `SHOW`.

## Lookup values

Reference data, seeded by the `0_init` migration. Not editable through the API.

```ts
// event_categories.code
type EventCategory = 'concert' | 'comedy' | 'theatre' | 'sports' | 'movie';

// seat_categories.code, in sort order
type SeatCategory = 'standard' | 'premium' | 'recliner';
```

## Event

### Event endpoints

| Method | Path              | Body                                                                               | Success                                 | Error                                                                                                             |
| ------ | ----------------- | ---------------------------------------------------------------------------------- | --------------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| POST   | `/api/events`     | `{ title, description, category, durationMins, language }`                         | 201 + created event + `Location` header | 400 invalid body, 409 title already used                                                                          |
| GET    | `/api/events`     | None                                                                               | 200 + paginated list                    | 400 invalid query params                                                                                          |
| GET    | `/api/events/:id` | None                                                                               | 200 + event                             | 400 invalid id, 404 not found                                                                                     |
| PATCH  | `/api/events/:id` | Any non-empty subset of `{ title, description, category, durationMins, language }` | 200 + updated event                     | 400 invalid body or `id` in body, 404 not found, 409 title already used or new `durationMins` makes shows overlap |
| DELETE | `/api/events/:id` | None                                                                               | 204 No Content                          | 400 invalid id, 404 not found, 409 event has shows                                                                |

### Event object

| Field        | Type   | Required on create | Rules                                                       |
| ------------ | ------ | ------------------ | ----------------------------------------------------------- |
| id           | string | No (server)        | UUID v7; read-only                                          |
| title        | string | Yes                | 1 to 100 characters; unique across events, case-insensitive |
| description  | string | Yes                | 20 to 2000 characters                                       |
| category     | string | Yes                | One of [`EventCategory`](#lookup-values)                    |
| durationMins | number | Yes                | Integer, 1 to 1440 (24 hours)                               |
| language     | string | Yes                | ISO 639-1 code, 2 lowercase letters (e.g. `en`, `hi`)       |

### Event list filters

| Param    | Type   | Description                                |
| -------- | ------ | ------------------------------------------ |
| search   | string | Case-insensitive contains match on `title` |
| category | string | Filter by one of the `EventCategory` codes |

Sorted by `title` ascending.

Changing `durationMins` moves `endsAt` of every show of the event. If that makes two shows on a screen overlap, the request returns 409 `EVENT_CONFLICT` and nothing changes.

## Screen

A screen belongs to one venue. Create and list are nested under the venue; single-screen routes are flat.

### Screen endpoints

| Method | Path                           | Body       | Success                                  | Error                                                                                |
| ------ | ------------------------------ | ---------- | ---------------------------------------- | ------------------------------------------------------------------------------------ |
| POST   | `/api/venues/:venueId/screens` | `{ name }` | 201 + created screen + `Location` header | 400 invalid body or id, 404 venue not found, 409 name already used at this venue     |
| GET    | `/api/venues/:venueId/screens` | None       | 200 + paginated list                     | 400 invalid id or query params, 404 venue not found                                  |
| GET    | `/api/screens/:id`             | None       | 200 + screen                             | 400 invalid id, 404 not found                                                        |
| PATCH  | `/api/screens/:id`             | `{ name }` | 200 + updated screen                     | 400 invalid body or `id` in body, 404 not found, 409 name already used at this venue |
| DELETE | `/api/screens/:id`             | None       | 204 No Content                           | 400 invalid id, 404 not found, 409 screen has shows                                  |

`Location` points to `/api/screens/:id`. Deleting a screen also deletes its seats.

### Screen object

| Field   | Type   | Required on create | Rules                                                          |
| ------- | ------ | ------------------ | -------------------------------------------------------------- |
| id      | string | No (server)        | UUID v7; read-only                                             |
| venueId | string | No (from path)     | UUID v7; read-only, a screen cannot move to another venue      |
| name    | string | Yes                | 1 to 100 characters; unique within the venue, case-insensitive |

Sorted by `name` ascending.

## Seat

A seat belongs to one screen. Create and list are nested under the screen; single-seat routes are flat.

### Seat endpoints

| Method | Path                           | Body                                                         | Success                                | Error                                                                                   |
| ------ | ------------------------------ | ------------------------------------------------------------ | -------------------------------------- | --------------------------------------------------------------------------------------- |
| POST   | `/api/screens/:screenId/seats` | `{ rowLabel, seatNumber, category }`                         | 201 + created seat + `Location` header | 400 invalid body or id, 404 screen not found, 409 seat already exists on this screen    |
| GET    | `/api/screens/:screenId/seats` | None                                                         | 200 + paginated list                   | 400 invalid id or query params, 404 screen not found                                    |
| GET    | `/api/seats/:id`               | None                                                         | 200 + seat                             | 400 invalid id, 404 not found                                                           |
| PATCH  | `/api/seats/:id`               | Any non-empty subset of `{ rowLabel, seatNumber, category }` | 200 + updated seat                     | 400 invalid body or `id` in body, 404 not found, 409 seat already exists on this screen |
| DELETE | `/api/seats/:id`               | None                                                         | 204 No Content                         | 400 invalid id, 404 not found, 409 seat is used by a show                               |

`Location` points to `/api/seats/:id`.

### Seat object

| Field      | Type   | Required on create | Rules                                                                                                   |
| ---------- | ------ | ------------------ | ------------------------------------------------------------------------------------------------------- |
| id         | string | No (server)        | UUID v7; read-only                                                                                      |
| screenId   | string | No (from path)     | UUID v7; read-only                                                                                      |
| rowLabel   | string | Yes                | 1 letter (`A` to `Z`), case-insensitive, stored uppercase; `(screenId, rowLabel, seatNumber)` is unique |
| seatNumber | number | Yes                | Integer, 1 to 100                                                                                       |
| category   | string | Yes                | One of [`SeatCategory`](#lookup-values)                                                                 |

### Seat list filters

| Param    | Type   | Description                               |
| -------- | ------ | ----------------------------------------- |
| category | string | Filter by one of the `SeatCategory` codes |

Sorted by `rowLabel` ascending, then `seatNumber` ascending.

### Seat layout

Creates many seats on a screen in one request. Each row gets seats numbered from 1 to `seatCount`.

| Method | Path                                  | Body       | Success                                      | Error                                                                                 |
| ------ | ------------------------------------- | ---------- | -------------------------------------------- | ------------------------------------------------------------------------------------- |
| POST   | `/api/screens/:screenId/seats/layout` | `{ rows }` | 201 + `{ data: { screenId, createdCount } }` | 400 invalid body or id, 404 screen not found, 409 a seat in the layout already exists |

- No `Location` header: the response holds a count, not a resource. List the seats with `GET /api/screens/:screenId/seats`.
- All or nothing: if any seat already exists on the screen, the request returns 409 and creates no seats.
- Rows that don't overlap existing seats are added. A screen with row `Z` accepts a layout for rows `A` to `C`.

| Field            | Type   | Rules                                                                     |
| ---------------- | ------ | ------------------------------------------------------------------------- |
| rows             | array  | 1 to 26 rows; row labels must be unique within the request                |
| rows[].rowLabel  | string | 1 letter (`A` to `Z`), case-insensitive, stored uppercase                 |
| rows[].seatCount | number | Integer, 1 to 100                                                         |
| rows[].category  | string | One of [`SeatCategory`](#lookup-values); applies to every seat in the row |

## Show

A show is one event playing on one screen at one time.

### Show endpoints

| Method | Path             | Body                                               | Success                                | Error                                                                                                                      |
| ------ | ---------------- | -------------------------------------------------- | -------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| POST   | `/api/shows`     | `{ eventId, screenId, startsAt, priceMinor }`      | 201 + created show + `Location` header | 400 invalid body or unknown `eventId` / `screenId`, 409 overlaps another show on this screen or screen has no seats        |
| GET    | `/api/shows`     | None                                               | 200 + paginated list                   | 400 invalid query params                                                                                                   |
| GET    | `/api/shows/:id` | None                                               | 200 + show                             | 400 invalid id, 404 not found                                                                                              |
| PATCH  | `/api/shows/:id` | Any non-empty subset of `{ startsAt, priceMinor }` | 200 + updated show                     | 400 invalid body, `id`, `eventId`, `screenId` or `endsAt` in body, 404 not found, 409 overlaps another show on this screen |
| DELETE | `/api/shows/:id` | None                                               | 204 No Content                         | 400 invalid id, 404 not found                                                                                              |

### Show object

| Field      | Type   | Required on create | Rules                                                                      |
| ---------- | ------ | ------------------ | -------------------------------------------------------------------------- |
| id         | string | No (server)        | UUID v7; read-only                                                         |
| eventId    | string | Yes                | UUID v7 of an existing event; set on create only                           |
| screenId   | string | Yes                | UUID v7 of an existing screen; set on create only                          |
| startsAt   | string | Yes                | ISO 8601 with offset; returned in UTC                                      |
| endsAt     | string | No (server)        | ISO 8601 in UTC; `startsAt` + the event's `durationMins`; read-only        |
| priceMinor | number | Yes                | Integer in paise, 0 to 2147483647 (Postgres `integer` max); `0` means free |

Shows on one screen can't overlap. The database enforces this on `[startsAt, endsAt)`, a half-open range, so a show may start at the exact time the previous one ends. An overlap returns 409 `SHOW_CONFLICT`.

Creating a show also creates its seat inventory: one available seat per seat on the screen, in the same transaction. A screen with no seats returns 409 `SHOW_CONFLICT` and no show is saved.

`endsAt` follows `startsAt` on PATCH and the event's `durationMins` when the event changes. Sending `endsAt` returns 400.

To move a show to another event or screen, delete it and create a new one.

### Show list filters

| Param    | Type   | Description                                                             |
| -------- | ------ | ----------------------------------------------------------------------- |
| eventId  | string | UUID; shows of this event. An id with no shows returns an empty list    |
| screenId | string | UUID; shows on this screen. An id with no shows returns an empty list   |
| from     | string | ISO 8601 with offset; `startsAt >= from`                                |
| to       | string | ISO 8601 with offset; `startsAt < to`; when both are sent, after `from` |

`from` and `to` can be sent alone or together. Both are compared as instants, so they can use different offsets. `to` not after `from` returns 400 with `to` in `details`.

`from` and `to` form a half-open range. For "shows on a day", the client sends local midnight to the next local midnight with its offset, e.g. `from=2026-11-20T00:00:00%2B05:30&to=2026-11-21T00:00:00%2B05:30` (`+` encoded as `%2B`).

Sorted by `startsAt` ascending, then `id` ascending so shows at the same time page in a stable order.
